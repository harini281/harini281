# 🚀 Featured Projects

## 🚕 UrbanFlow AI

### Urban Mobility Intelligence & Prediction

A Machine Learning and data analytics project developed around large-scale urban mobility data.

- 📊 Processed approximately **48.6 million taxi trip records**
- 💰 Built a **Base Fare Prediction** model
- ⏱️ Developed an **ETA / Trip-Time Prediction** model
- 🚕 Built a **Taxi Demand Forecasting** model
- 📍 Performed **Pickup Hotspot Analysis**
- 🔄 Performed **Origin-Destination Flow Analysis**
- 🌅 Analyzed **AM vs PM mobility patterns**
- 🧠 Applied feature engineering and chunked large-scale data processing
- 📈 Evaluated predictive models using **MAE, RMSE and R²**

### Model Results

| Task | MAE | RMSE | R² |
|---|---:|---:|---:|
| Base Fare Prediction | 3.9314 | 8.1008 | 0.7944 |
| ETA Prediction | 4.1480 min | 20.8903 min | 0.2676 |
| Demand Forecasting | 22.5144 trips/hour | 34.0419 trips/hour | 0.9394 |

**Tech:** Python • Pandas • Scikit-learn • HistGradientBoostingRegressor • Feature Engineering • Data Analytics

👉 [View UrbanFlow AI](https://github.com/harini281/UrbanFlow_AI)
